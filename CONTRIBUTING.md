# Contributing

Bug reports and pull requests are welcome.

1. Fork the repo and create a branch from `main`.
2. You need JDK 25. Run `./gradlew build` before opening a PR; CI runs the same command.
3. Keep changes focused, and add a line to `CHANGELOG.md` under "Unreleased" for anything players will notice.
4. User-visible text goes into both `en_us.json` and `ru_ru.json`.

For bugs, please include `logs/latest.log` and the mod version.
