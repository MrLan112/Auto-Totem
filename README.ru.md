# Auto Totem

Небольшой клиентский мод для Fabric: кладёт Тотем бессмертия в левую руку, чтобы не копаться в инвентаре посреди боя.

Версия Minecraft: **1.21.11**. Нужен Fabric API, Mod Menu по желанию. На сервер ставить ничего не нужно.

## Как работает

Когда оффхенд пуст (например, тотем только что сработал), мод находит другой тотем в инвентаре или хотбаре и перекладывает его в оффхенд. Остальное - необязательные настройки.

Клавиши по умолчанию: `O` - включить/выключить мод, `B` - открыть настройки. Меняются в стандартном меню управления.

## Настройки

Всё на одном экране, по разделам; оба HUD видны сразу, их можно перетаскивать мышью.

- **Автоэкипировка** - задержка перед надеванием в тиках (0-40, 20 тиков = 1 секунда).
- **Порог здоровья** (по умолчанию выключен) - тотем переходит в оффхенд, только когда здоровье упало до выбранного числа сердец или ниже. Когда здоровье восстановилось, тотем возвращается на своё место. Есть пункт «переместить после первого удара».
- **Stats HUD** (по умолчанию выключен) - сколько тотемов осталось и когда сработал последний.
- **Notification HUD** - короткое сообщение «Тотем сработал».
- **Звук оповещения** - по умолчанию обычный звук тотема. Можно импортировать свой файл с компьютера (WAV, AIFF, AU, до 30 секунд; OGG и MP3 не поддерживаются). При своём звуке ванильный звук вашего тотема отключается. Есть регулировка громкости.

Конфиг: `config/autototem.json`, импортированный звук копируется в `config/autototem/`.

## Что стоит знать

- Выброс тотема на `Q` тоже считается срабатыванием - мод видит только уменьшение количества.
- На многих серверах автоматические действия с инвентарём запрещены. Смотрите правила сами.
- В креативе и режиме наблюдателя мод ничего не делает.

## Сборка

Нужен JDK 21: `./gradlew build` (на Windows `.\gradlew build`). Готовый jar - в `build/libs/`.
